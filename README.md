# Счётчик игровых постов

Считает посты в разделах 19 (игра), 20 (альтернатива), 21 (заброшенные), 65 (доигранные).
Первый пост темы не считается. Посты удалённых аккаунтов (user_id 1) не считаются.

## Файлы

- `updater/update.mjs` — подсчёт, запускается в GitHub Actions раз в час.
- `.github/workflows/postcount.yml` — расписание и публикация в ветку `data`.
- `forum/gameposts.js` — скрипт для форума: выводит счётчик в постах и профиле.

## Настройка

1. На форуме: аккаунт-читатель с логином латиницей, группа с правом только читать разделы 19, 20, 21, 65.
2. В репозитории (публичном), Settings → Secrets and variables → Actions:
   - Variables: `FORUM_URL` = адрес форума
   - Secrets: `FORUM_LOGIN`, `FORUM_PASSWORD`
3. Actions → «Подсчёт игровых постов» → Run workflow, «Пробный запуск» включён,
   в `check_uids` — несколько id игроков. В логе будут их числа: сверить с ночным скриптом.
4. Если числа сходятся — запустить без пробного режима. Первый подсчёт растянется на несколько
   запусков: вручную с лимитом 1800 — 2–3 запуска, по расписанию (по 400) — около суток.
5. Когда в `postcount.json` поле `pending` станет 0 — подключить `forum/gameposts.js`,
   заменив в нём `OWNER/REPO` на свой репозиторий.

## Нагрузка на форум

- Обновление: запросы по одному, пауза 1,5 с, максимум 400 за запуск (около 10 минут).
  При 429/5xx — пауза 10 с, потом 30 с; после трёх ошибок подряд запуск останавливается,
  сделанное сохраняется.
- Обычный запуск: темы всех четырёх разделов, отсортированные по последнему посту; читается только верх
  списка — где писали после прошлого запуска. Около 10 запросов. Посты в архивах тоже видны.
- Полная проверка (галочка при ручном запуске): все темы, около 180 запросов. Нужна, если удаляли темы
  или переносили эпизоды в игровые разделы из других разделов.
- Скрипт на форуме к API не обращается: раз в час загружает `postcount.json` с GitHub.
- Чтобы обновлять раз в сутки, в `postcount.yml` поменять `'17 * * * *'` на `'17 3 * * *'`
  (03:17 UTC). Лучше сделать это после первичного подсчёта: он идёт по одной порции за запуск.

## Защита

Если тем вдруг стало на 5% меньше, чем в прошлый раз (например, у читателя пропал доступ),
запуск останавливается и ничего не удаляет.
